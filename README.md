# Telegram Bot – отслеживание онлайн-статуса

Бот запоминает имя каждого пользователя и оповещает всех остальных, когда кто-то появляется в сети или выходит из неё.

## Как работает

1. Пользователь пишет боту → бот просит представиться
2. Пользователь вводит имя → бот запоминает
3. Когда пользователь пишет любое сообщение, бот считает его **онлайн**
4. Если от пользователя нет сообщений 2 минуты, бот считает его **офлайн**
5. При каждом изменении статуса бот отправляет остальным:  
   `Имя есть в наличии` / `Имя нет в наличии`

## Переменные окружения

| Переменная  | Описание |
|-------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather |

## Деплой на Render

1. Запуши репозиторий на GitHub
2. На [render.com](https://render.com) создай **Background Worker**
3. Подключи GitHub-репозиторий
4. Добавь переменную `BOT_TOKEN`
5. Укажи команду запуска:
   ```
   python bot.py
   ```

## Локальный запуск

```bash
export BOT_TOKEN=токен_от_botfather
pip install -r requirements.txt
python bot.py
```
